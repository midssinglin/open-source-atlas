每週排程從各平台自動抓到的新興熱門專案，依「日均星數」排序。還沒經過人工整理，只有基本資訊與初步風險。維護者可在 GitHub Actions 執行「產生收錄草稿」，讓 AI 先寫好介紹再人工審核。

每週一自動更新，最近一次 。「即時更新數據」會直接向各平台讀取最新星數，結果只存在你的瀏覽器。Bitbucket 不提供星數。 安全分數綜合授權、維護狀態、OpenSSF Scorecard、依賴漏洞（OSV）與安裝方式計算，屬於靜態風險評估，不是防毒掃描。
